# Go backend

The contract (`contracts/`, 2.0.2) in Go: standard library `net/http`, the server interface generated from the
contract, SQL over Neon's serverless HTTP endpoint. A Render free web service that sleeps when idle:
`https://typhoon-replay-go.onrender.com`, and behind the site at `https://replay.krtmtthw.dev/api/go/`.

Hosting and the departures from the recorded stack: `docs/architecture/DECISIONS.md`, "Hosting the Go, Node and
Rust backends" (Go was measured on Cloudflare Workers first, via TinyGo; it ran over the free CPU limit).

| | |
|---|---|
| Language | Go 1.27.3, standard library `net/http` |
| Contract | oapi-codegen 2.8.0 (a `go.mod` tool) generates the models, parameter structs and the std-http `ServerInterface` from `contracts/dist/openapi.3.0.json`; the generated wrapper binds every parameter, the handlers check the rest of the schema (ranges, enums, patterns) |
| Database | `internal/neon`: Neon serverless SQL over HTTP. One HTTPS request per transaction (read-only batch, `SET LOCAL statement_timeout = 5000`), no pool to keep the compute awake. Replaces pgx + sqlc from the recorded stack |
| JSON | `internal/jsonw`, an append-only writer: numbers keep Postgres's exact decimal text, no `null`s |
| Image | distroless static, nonroot, ~17 MB |

## Layout

```
cmd/server/         main: config from the environment (CONTRACT-GUIDE §11), graceful shutdown
internal/api/       generated by oapi-codegen (do not edit api.gen.go; `go generate ./...`)
internal/app/       the operations: routing, storms, places/hits, meta/probes, live (snapshot, SSE, test hook), SQL
internal/web/       contract HTTP rules: §4 headers, gzip, problems, lenient query parsing, ETags, cursors, rate limit
internal/neon/      Neon HTTP client
internal/jsonw/     JSON writer
```

Optimisations and guards:
- **One round trip per request.** The dataset version runs in the same transaction as the operation's queries; a
  conditional request (the edge revalidating) is answered 304 from a 5 s cache of that version, without the
  database.
- **gzip** over 1 KB (Render bills outbound bytes), JSON built without reflection, responses ≤ 64 KB at the maximum
  `limit`.
- **No idle work.** Nothing touches the database while no request or live stream is open, so Neon scales to zero
  and Render sleeps after 15 minutes. A live stream polls `live.revision` every 2 s and ends after 30 minutes
  (the browser resumes with `Last-Event-ID`); at most `TR_MAX_STREAMS` (200) are open.
- **Per-IP limit** (`TR_RATE_LIMIT_PER_MINUTE`, default 600) behind the edge's own; `X-Forwarded-For` is trusted only
  with the edge secret (`TR_EDGE_SECRET`).

## Run locally

Needs Go 1.27.3, Node 24, Docker.

```sh
just db-up                                   # PostGIS + migrations + seed (repo root)
docker run -d --name neon-proxy -p 4444:4444 \
  -e PG_CONNECTION_STRING=postgres://tr:tr@host.docker.internal:5432/typhoon \
  ghcr.io/timowilhelm/local-neon-http-proxy@sha256:cd2ae14edf2feafbc3330492de5c80506f77274c3bd013154cdef697bdeb768a
npm --prefix ../../contracts run bundle && mkdir -p contract && cp ../../contracts/dist/openapi.json contract/
DATABASE_URL=postgres://tr:tr@db.localtest.me:5432/typhoon NEON_HTTP_URL=http://localhost:4444/sql \
  TR_TEST_HOOKS=1 TR_RATE_LIMIT_PER_MINUTE=0 PORT=8084 go run ./cmd/server
BASE_URL=http://localhost:8084 IMPL=go npm --prefix ../../contracts run conformance
go test ./...
```

The image: `docker build -f api/go/Dockerfile -t typhoon-replay-go .` from the repository root.

## Deploy

Render service `typhoon-replay-go` (free plan, Singapore, Docker, `api/go/Dockerfile`, build context the repository
root), deploying `main` after the GitHub checks pass, for changes under `api/go/**` and `contracts/**`. Environment:
`DATABASE_URL` and `TR_EDGE_SECRET` (secrets, set in Render, never in the repo), `TR_SITE_ORIGIN`. Health check
`/healthz`.
