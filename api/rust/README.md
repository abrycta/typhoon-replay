# Replay API: Rust backend

A Cloudflare Worker, `replay-api-rust` (free plan), serving contract `2.0.2`
([`contracts/docs/CONTRACT-GUIDE.md`](../../contracts/docs/CONTRACT-GUIDE.md); see [`impl.json`](impl.json)). Hosting
decision: [`docs/architecture/DECISIONS.md`](../../docs/architecture/DECISIONS.md), "Update 2026-10-22". Background
research (written for a Render + SQLx target): [`docs/ARCHITECTURE-RESEARCH.md`](docs/ARCHITECTURE-RESEARCH.md).

## Stack

| Layer | Choice |
|---|---|
| Runtime | Rust 1.99.1 (`rust-toolchain.toml`) → `wasm32-unknown-unknown`, built by `worker-build` 0.8.7, run by workers-rs 0.8.7 |
| HTTP | Axum 0.8.9 `Router` (default features off) called from the Worker's `fetch` handler; handlers are `#[worker::send]` |
| Contract-first | `crates/contract`: every `components.schemas` entry as a serde type, generated by typify 0.8.0 (`crates/codegen`) and committed. Handlers build these types from rows, so enums, patterns and required members are the contract's; CI regenerates and fails on a diff |
| Data | Neon serverless SQL over HTTP (`src/neon.rs`): one `POST https://{host}/sql` batch per request through `worker::Fetch`, read-only, `SET LOCAL statement_timeout = 5000` first and the dataset-version query in the same batch, so a catalogue read is one round trip. SQLx can't run on Workers (no Tokio sockets), and Hyperdrive would keep Neon's compute awake |
| Live | SSE from a polling stream: every 2 s, at most 44 polls (the 50-subrequest cap per invocation), the stream ends after 90 s and the browser resumes with `Last-Event-ID` |
| Guards | Workers Rate Limiting binding `RATE_LIMITER` (namespace 1003, 600/60 s per IP, keyed on `X-Forwarded-For` only when `X-Edge-Secret` matches); responses over 1 KB compressed natively by the runtime (`Content-Encoding` set, no wasm CPU); page sizes capped by the contract (≤ 100); test hook body ≤ 64 KB |

Layout: `crates/server/src/` — `lib.rs` (fetch, router, the §4 headers, Cache-Control, compression, problem rendering),
`web.rs` (request context, problems, ETags, cursors, lenient query parsing, parameter checks), `neon.rs`, `sql.rs`
and `rows.rs` (SQL fragments ported from the Java reference, rows → contract types), and one module per area
(`meta`, `storms`, `places`, `live`). No request-scoped globals: config and the database client are built per request
from `Env`; only the isolate's start time and its open-stream count are isolate-wide.

## Build, run, test

```sh
cd api/rust
npm ci && npm run build                                   # worker-build → crates/server/build (size checked)
DATABASE_URL=postgres://tr:tr@db.localtest.me:5432/typhoon scripts/serve-local.sh 8090 1   # local workerd
cargo test -p server --lib                                # unit tests (cursors, ETags, query parsing)
cargo run -p codegen && cargo fmt --all                   # regenerate the contract types (after `npm run bundle` in contracts/)
```

`serve-local.sh` expects Neon's SQL-over-HTTP proxy for a plain PostGIS (`NEON_HTTP_URL`, default
`http://localhost:4444/sql`; the image is pinned by digest in `.github/workflows/rust.yml`). Then
`BASE_URL=http://localhost:8090 IMPL=rust npm --prefix contracts run conformance`. CI (`rust.yml`) runs the full
scenario suite, Schemathesis and, on `main`, `wrangler deploy` plus the dataset-independent scenarios against the
deployed Worker.

## Configuration

Vars (`wrangler.jsonc`): `TR_SITE_ORIGIN`, `TR_TEST_HOOKS` ("0" in production), `TR_RATE_LIMIT_PER_MINUTE` ("0"
turns the limiter off; the limit itself is the binding's), `TR_COMMIT` (deploy: `--var TR_COMMIT:<sha>`), optional
`NEON_HTTP_URL`. Secrets, set once, never in files:

```sh
security find-generic-password -s neon-database-url -w | npx wrangler secret put DATABASE_URL
security find-generic-password -s typhoon-edge-secret -w | npx wrangler secret put TR_EDGE_SECRET
```

## Notes

- Cloudflare's front door answers 400 to a request that repeats `If-None-Match` as two headers, before the Worker
  runs; the Worker itself joins split headers (local workerd, service bindings).
- Numbers are written by serde (`125.0`, not `125`); the contract compares values, not bytes (CONTRACT-GUIDE §0, §3).
- Frozen showcase policy: exact versions in `Cargo.toml`/`Cargo.lock`, `package-lock.json`, `rust-toolchain.toml`.
